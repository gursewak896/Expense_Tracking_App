📊 REST API OPERATIONS:

GET - getTransactions()
  └─ Purpose: Fetch all transactions
  └─ Query: users/{userId}/transactions (sorted by date DESC)
  └─ Returns: List<TransactionModel>
  └─ Used in: HomeView on init, refresh after operations

POST - addTransaction()
  └─ Purpose: Create new transaction
  └─ Sends: TransactionModel converted to JSON
  └─ Returns: TransactionModel with auto-generated ID
  └─ Used in: ExpenseFormProvider.saveTransaction()

PUT - updateTransaction()
  └─ Purpose: Update existing transaction
  └─ Sends: Updated TransactionModel
  └─ Modifies: Specific document by ID
  └─ Used in: ExpenseFormProvider.updateTransaction()

DELETE - deleteTransaction()
  └─ Purpose: Remove transaction
  └─ Target: Specific document by ID
  └─ Used in: TransactionCard, ExpenseFormProvider
